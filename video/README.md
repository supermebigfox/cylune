# CYLUNE 发布影片制作指南

这套文件用于制作一支 70 秒、16:9 横屏、4K 的 CYLUNE 软件发布影片。成片采用产品发布短片式的纯视觉叙事：没有人物、数字人或旁白，通过真实软件画面、极简英文标题、音乐和音效完成表达。

## 最终交付

- 4K 母版：3840×2160、30fps、ProRes 422 HQ、Rec.709。
- 4K 发布版：3840×2160、30fps、H.265 Main10。
- 1080p 审片版：1920×1080、30fps、H.264。
- 总时长：70 秒，允许编码结果存在不超过 1 帧的时长误差。
- 片尾状态：`Available now.`

## 核心制作原则

真实产品画面与生成画面必须分工明确：

- CYLUNE 软件界面、中文文字、数据、Logo 和黑洞交互全部使用真实录屏或现有品牌资产。
- Seedance 2.0 只生成镜头 04 的光束转场和镜头 11 的光纤聚合动画。
- 英文标题全部在剪辑软件中后期叠加。
- 不把软件截图交给模型重新绘制，不接受模型生成的文字、数据或 Logo。
- 不使用一条长 Prompt 一次生成整支影片；每个生成镜头独立制作和筛选。

## 推荐工具

### 生成模型

主模型使用 **Seedance 2.0 的“全能参考 / multimodal reference-to-video”模式**。官方资料说明该模型可同时参考文字、图片、视频和音频，并支持 15 秒输出；这适合使用真实黑洞末帧、现有 Logo 和冰白海报约束视觉连续性。

- 官方模型页：<https://seed.bytedance.com/zh/seedance2_0>
- 官方发布说明：<https://seed.bytedance.com/blog/seedance-2-0-official-launch>
- 可用入口：即梦 AI 的视频生成页面选择 Seedance 2.0，或豆包 App 选择 Seedance 2.0。

如果使用的平台暂时没有 Seedance 2.0，可用 Runway 或 Kling 的图生视频模式做镜头 04 和 11；它们只是备用，不改变真实 UI 和真实黑洞的使用原则。

### 录屏

- 首选：macOS 截屏工具或 OBS Studio。
- 录制规格：3840×2160、60fps、高码率。
- 关闭桌面通知、信息预览和自动隐藏菜单栏造成的跳动。
- 鼠标点击必须在真实交互镜头中保持自然，纯展示镜头隐藏鼠标。

### 剪辑与合成

- 首选：DaVinci Resolve Studio 或 Final Cut Pro。
- 可选：After Effects，用于复杂遮罩、光束和 Logo 聚合合成。
- 不依赖高级合成时，DaVinci Resolve 的 Fusion 页面即可完成全部工作。

## 固定生产顺序

### 01 捕获真实 CYLUNE 画面

按照 [`assets.md`](assets.md) 逐项录制。先完成桌面黑洞，再录制切片、耗材库、AMS 映射、打印记录和成功结算。任何私人信息出现在画面中都必须重录，不依赖后期模糊处理。

### 02 导出静帧与品牌参考

从录屏中导出干净的 UI 静帧，并直接引用以下现有品牌母版：

- `../brand/poster-final-4k.png`
- `../brand/cylune-master.png`
- `../brand/cylune-mark-transparent.png`

不要复制或再次压缩品牌母版。

### 03 生成镜头 04 和镜头 11

按照 [`prompts.md`](prompts.md) 使用 Seedance 2.0 全能参考模式。每个镜头先生成 4 个版本，选定方向后最多追加 2 次受控重试。不要在同一轮里随意改变风格、构图和动作。

### 04 组装 12 镜头母版

建立 3840×2160、30fps、70 秒时间线。按照 [`script.md`](script.md) 的时间码放置镜头，先完成无字幕、无音乐的 picture lock，再添加标题和声音。

### 05 加入英文标题与声音

字幕、Logo 字标和 `Available now.` 均由剪辑软件生成或放置。音乐、吸入、射流、界面点击和庆祝声按照 [`edit.md`](edit.md) 卡点。

### 06 校验和导出

逐帧检查黑洞边缘、模型缩略图、耗材数据、Logo 形状和生成镜头的闪烁。完成画面检查后再输出母版、发布版和审片版。

## 工作边界

### 允许交给 Seedance 的内容

- 蓝紫色光束穿入冰白空间。
- 抽象玻璃、光纤、粒子和柔和虹彩折射。
- 彩纸转化为光纤并向中心汇聚的动作。

### 必须保持真实的内容

- 桌面黑洞的外观、扭曲、旋转和文件吸入。
- CYLUNE 窗口、中文界面、按钮、数据和缩略图。
- 真实库存扣减和窗口内庆祝动画。
- CYLUNE Logo 的轮廓、线束、颜色和字标。

### 明确禁止

- 让模型“重新设计”黑洞或 Logo。
- 让模型生成可读的界面、中文或英文字幕。
- 在 UI 上添加虚构功能、设备或数据。
- 使用人物、手部特写、数字人或口播。
- 使用赛博朋克城市、故障艺术、夸张镜头抖动或随机粒子风暴。
