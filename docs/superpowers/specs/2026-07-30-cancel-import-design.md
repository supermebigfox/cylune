# CYLUNE 取消导入设计

## 目标

用户误导入切片文件时，可以放弃这条尚未结算的打印任务，不需要为了离开页面而扣减耗材。

## 交互

- 打印任务尚未结算时，在“确认耗材映射”旁显示“取消此次导入”。
- 点击后显示确认对话框，明确说明不会扣减耗材。
- 确认取消后返回打印任务空状态，并刷新待处理数量。
- 已结算任务不显示该按钮，继续使用现有“撤销本次扣减”。

## 数据行为

- 后端只允许删除 `outcome IS NULL` 的任务。
- 在同一事务中删除该任务的 `job_mappings`，再删除 `print_jobs` 记录。
- 不创建或修改账本事件，不改变任何实体卷余额或 AMS 槽位。
- 保留 `parse_cache`；相同文件再次导入时复用解析结果并创建新的待处理任务。
- 同步清除指向该任务的 `pending_job_id` 设置，避免菜单栏重新打开已取消任务。

## 错误处理

- 任务不存在或已经结算时返回稳定错误，不做部分删除。
- 前端失败时保留当前任务页面并显示现有错误提示。
- 忙碌期间禁用取消与结算按钮，避免并发操作。

## 测试

- 后端：取消未结算任务后任务/映射消失，缓存保留，余额及账本不变；已结算任务拒绝取消。
- 前端：未结算时显示按钮、确认后调用取消 API；用户关闭确认框时不调用；已结算时隐藏。
- 应用层：成功取消后清空当前预览、刷新库存与待处理数量。

## 构建产物

- 正式测试包只保留 `发布/CYLUNE.app`。
- 打包完成并复制正式包后，移除 `target/release/bundle/macos/CYLUNE.app` 临时副本，避免 Spotlight 显示两个 CYLUNE。
