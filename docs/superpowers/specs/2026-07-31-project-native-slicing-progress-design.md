# CYLUNE 原项目设置切片与百分比进度设计

## 目标

CYLUNE 负责读取普通 3MF、调用本机 Bambu Studio CLI 完成后台切片，并提取打印重量、时间、层数和缩略图。用户不在 CYLUNE 中调整打印工艺；切片结果应保留 3MF 已保存的自定义参数。

切片页只保留文件概要、目标机器概要、开始切片、取消切片，以及必要的机器不匹配确认。

## 设置来源

- 目标打印机与喷嘴：使用“打印机”页面中用户设置的首选机器。
- 打印工艺：直接继承 3MF，包括层高、速度、墙厚、填充、熨烫、支撑、打印板、温度和其他自定义工艺值。
- 耗材配置：继承 3MF 内嵌的耗材配置，不在切片页允许手动替换。
- CYLUNE 不再为普通流程生成会覆盖项目工艺的临时 process/filament 配置。
- 调用 Bambu Studio CLI 时只在需要确定目标硬件时加载首选机器配置，避免比 3MF 优先级更高的工艺配置覆盖项目参数。

## 机器不匹配

当 3MF 内嵌机型或喷嘴与首选机器不同：

1. 切片页显示双方机器与喷嘴信息。
2. 用户必须明确勾选“确认改用我的首选机器”后才能开始。
3. 确认只授权替换目标机器与喷嘴，不授权覆盖 3MF 的工艺、支撑、填充或耗材参数。
4. 如果 Bambu CLI 判断项目工艺确实无法用于目标机器，CYLUNE 返回明确的不兼容错误，不静默套用默认工艺。

机器一致时不要求额外确认。

## 切片页交互

移除以下可编辑控件：

- 工艺与层高
- 打印板
- 填充率
- 生成支撑
- 每个工具的耗材预设
- 目标打印机下拉选择

页面只读展示：

- 当前 3MF 文件与打印盘数量
- 自动选中的首选机器和喷嘴
- 3MF 内嵌工艺、打印板、填充、支撑状态与耗材概要（读取到时显示）
- 机器不匹配提示与确认框（仅不匹配时显示）
- 开始切片与取消切片按钮

## 进度

- 为 Bambu Studio CLI 创建每任务独立的进度管道，并通过官方 `--pipe` 参数接收进度消息。
- 后端解析有效的数值进度，限制在 `0–100`，保证同一任务只向前推进。
- 前端始终显示确定型进度条和整数百分比，不再以“部署环境、正在验证”等阶段文字充当主要进度。
- 启动时显示 `0%`，完成导入打印记录后显示 `100%`。
- 如果某个受支持的 Bambu Studio 版本没有发出可解析的管道进度，CYLUNE 仍显示进度条，但不得伪装成精确的切片百分比；应使用保守的阶段进度并在完成时到达 `100%`，同时保留诊断信息用于兼容适配。
- 取消后立即停止更新，终止 CLI，并删除任务临时目录。

## 临时文件与结果导入

- 切片后的 G-code 3MF 只保存在 CYLUNE 私有任务临时目录。
- CYLUNE 从临时文件读取重量、时间、层数、分盘信息和缩略图，写入打印记录。
- 导入成功、失败或取消后均清理临时切片文件；启动时继续清理孤儿任务目录。
- 不向用户输出切片文件。

## 错误处理

- 自定义工艺不兼容应映射为稳定、三语言可读的错误，而不是展示原始 CLI 返回值。
- 机器不匹配但用户未确认时，禁用开始切片。
- Bambu Studio 未安装、进度管道失败、CLI 失败、取消和结果导入失败分别处理。
- 进度功能异常不得导致切片进程挂起或无法取消。

## 测试

- 前端测试：切片页不存在任何工艺覆盖控件；机器不匹配确认仍存在；提交请求不携带工艺覆盖值；进度从 `0%` 连续更新并最终为 `100%`。
- Rust 单元测试：只加载目标机器而不加载 process/filament；管道消息解析、范围限制、单调递增、非法消息与取消竞态。
- 真实文件回归：自定义工艺的“曼尼面具”文件成功切片；Poopy 结果保持约 `221g`；风洞多盘结果保持约 `782g`。
- 完成后运行全部 Rust 与前端测试，再统一打包一次 `CYLUNE.app`。
