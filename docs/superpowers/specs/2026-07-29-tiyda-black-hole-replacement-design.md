# CYLUNE tiyda 黑洞替换设计

日期：2026-07-29  
状态：已获用户批准

## 目标

用 [`tiyda/blackhole-desktop`](https://github.com/tiyda/blackhole-desktop) 的 macOS 原版实现替换 CYLUNE 当前自写的黑洞渲染与屏幕捕获代码。最终效果以 tiyda 原版为准，不再混用此前的自定义透镜、粒子或捕获实现。

CYLUNE 只在原版外增加产品必需的交互外壳：

- 黑洞本体不自动漂移；
- 用户可手动拖动黑洞，并持久化位置；
- 黑洞可跨显示器移动；
- 尺寸、30/60 FPS、显示/隐藏和重置位置继续由 CYLUNE 设置控制；
- Finder 文件拖入黑洞后进入 CYLUNE 导入流程，不进入废纸篓。

## 原版保真边界

以下代码与行为来自 tiyda 原版，并作为视觉真源：

- `BlackHole.metal` 的光线追踪、引力透镜、事件视界、光子环、吸积盘、预设参数与透明边界；
- `MetalBlackHoleView.m` 的 MetalKit 渲染循环；
- `SCScreenshotManager` 的应用最上层背景捕获方式；
- 原版拖入文件时显示的吸入光圈；
- 原项目的 MIT 许可证与第三方署名。

允许的视觉源码改动只有一项：把着色器内部随时间漂移的中心坐标改为由 CYLUNE 传入的固定中心坐标。时间、吸积盘动画、光线追踪与预设参数保持运行，不通过把速度设为零来冻结画面。

不移植其他仓库的鼠标引力、光标绕转、光标残影或自动成长功能。

## 替换范围

停止编译并删除 CYLUNE 当前自写的以下黑洞实现：

- `src-tauri/native/mac/capture.mm`
- `src-tauri/native/mac/render.mm`
- `src-tauri/native/mac/shader.metal`
- `src-tauri/native/mac/pet.mm` 中的自定义渲染、捕获、粒子与动画代码
- 仅服务于上述旧实现的测试辅助代码

保留业务层：

- Rust 侧的导入、解析、库存、任务和结算逻辑；
- 黑洞显示设置的持久化；
- 支持文件类型与安全校验；
- 原有 Tauri 主程序和菜单栏入口。

新的 macOS 原生层由两部分组成：

1. `tiyda` 视觉层：尽量贴近原仓库文件布局和命名，保留来源注释。
2. `CYLUNE` 适配层：负责 Rust 回调、固定位置、跨屏、手动拖动、尺寸、帧率、显示状态与生命周期。

## 窗口与位置

- 每块显示器创建一个透明视觉 Pane，以便背景捕获和跨屏正确工作。
- 全局只显示一个黑洞；只有包含当前固定中心点的 Pane 绘制黑洞。
- 默认使用 tiyda 的“应用最上层”模式，使黑洞不会因普通应用窗口遮挡而消失。
- 视觉 Pane 点击穿透；黑洞中心上方设置一个小型交互窗口。
- 用户按住黑洞中心拖动时，只移动黑洞位置，不导入桌面上被它经过的文件。
- 只有用户主动将 Finder 文件拖入黑洞并在目标内松开，才触发导入。
- 松开黑洞后保存全局坐标和显示器标识；显示器断开时回到主显示器安全区域。
- 不运行任何自动漂移、随机移动或定时位置更新。

## 实时背景

- 使用 tiyda 原版 `SCScreenshotManager` 路径，不再使用 CYLUNE 当前的 `SCStream + IOSurface` 实现。
- 应用最上层模式排除 CYLUNE 自身窗口，避免递归镜像。
- 背景按照原版约 100 ms 的节流间隔持续请求新截图并转换为 Metal 纹理。
- 捕获成功后只能用最新完成的纹理替换当前纹理。
- 捕获失败或权限缺失时使用当前显示器壁纸作为后备，不长期显示一张误导性的旧应用截图。
- 屏幕录制权限只用于本机内存中的屏幕背景捕获，不录音、不联网、不保存截图。

## 文件导入

原版 `TrashDropView` 的废纸篓操作替换为 CYLUNE 导入回调：

1. Finder 拖入文件；
2. 原生层只选择第一个受支持的普通文件；
3. 支持 `.3mf`、`.gcode`、`.gcode.3mf`；
4. 原生层复制并规范化路径后发送给 Rust；
5. Rust 复用现有稳定性检查、解析和待处理任务创建流程；
6. 导入成功后播放原版吸入反馈；
7. 导入失败时文件保持不变，并显示 CYLUNE 错误状态。

拖动黑洞本体、经过桌面文件或把黑洞放到文件上方，都不会触发导入。

## 设置映射

- 黑洞类型“真实扭曲”：tiyda 原版实时背景。
- 黑洞类型“轻量模式”：保留为权限缺失或用户主动选择时的壁纸背景模式，不运行旧自定义着色器。
- 外观：第一阶段只保留当前 CYLUNE 已暴露的 Gargantua 与 Fusion 映射；映射值直接使用 tiyda 原版预设，不重调参数。
- 尺寸：现有 300–900 px 设置映射为原版 `size` 参数。
- 帧率：30/60 FPS 映射到 `MTKView.preferredFramesPerSecond`。
- 显示、隐藏、重置位置：由适配层实时应用。

## 生命周期和错误处理

- 应用睡眠、隐藏或退出时停止 Metal 绘制和截图请求。
- 应用唤醒或显示器变化时重建 Pane，并恢复已保存位置。
- 截图回调使用代次标识，旧 Pane 销毁后的迟到结果不得写入新 Pane。
- 导入回调在原生层立即复制路径，避免拖放对象释放后出现悬空引用。
- 原生资源释放顺序为：停止截图请求、停止 MTKView、关闭交互窗口、关闭视觉 Pane、释放纹理。

## 测试与验收

自动测试覆盖：

- 固定中心不会随时间变化；
- 吸积盘和原版时间动画仍随时间变化；
- 30/60 FPS 正确映射；
- 手动拖动只更新位置，不产生导入事件；
- 只有受支持的 Finder 文件主动拖入目标才产生一次导入；
- 多显示器切换后只显示一个黑洞；
- 隐藏、睡眠和退出停止截图；
- 捕获失败不复用过期应用截图；
- 原版预设常量和 MIT 归属文件被保留。

人工验收覆盖：

- 与 tiyda 原版并排录屏比较外观、边界、动画和扭曲；
- 在动态视频或滚动网页上观察背景持续变化，不能只看粒子动画；
- 拖动黑洞跨越桌面文件时不导入；
- 把测试 `.gcode.3mf` 主动拖入后进入 CYLUNE 待处理任务；
- 黑洞重启后保持位置且不会自行移动；
- 黑洞在普通应用上方可见，并实时扭曲当前画面。
