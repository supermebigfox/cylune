# 真实扭曲黑洞桌面宠物设计

日期：2026-07-27  
状态：用户已确认交互与技术方向  
目标平台：macOS 优先，保留 Windows 原生渲染扩展边界

## 1. 目标

在现有拓竹耗材管家中增加一个常驻桌面的黑洞宠物。用户可以拖动黑洞到任意显示器，也可以把已切片打印文件拖入黑洞完成导入。

黑洞提供两种类型：

- 真实黑洞：捕获黑洞所在显示器的实时画面，通过 Shader 折射黑洞后方的桌面像素。
- 轻量黑洞：不捕获屏幕、不折射桌面，但保留黑洞造型、待处理状态与吞噬动画。

黑洞不替代现有主程序。耗材库、AMS Lite 槽位、任务映射、打印结果和耗材结算继续在主程序中管理。

## 2. 非目标

- 不扫描桌面、下载目录或 Finder 当前选区。
- 不自动判断打印机是否已经完成、失败或取消。
- 不把屏幕画面、打印文件或耗材数据上传到网络。
- 不在第一版实现 Windows 屏幕捕获和 D3D 渲染。
- 不让黑洞覆盖整个屏幕或阻止黑洞区域以外的正常操作。

## 3. 用户体验

### 3.1 启动与常驻

- 启动耗材管家后，黑洞恢复到上次保存的位置、尺寸、类型和帧率。
- 黑洞默认常驻桌面，并保持在普通窗口上方。
- 菜单栏图标单击时隐藏或召回黑洞。
- 菜单栏图标右键显示：打开主程序、重置黑洞位置、隐藏黑洞、退出。
- 应用必须为单实例，重复打开时激活现有实例，不创建第二个菜单栏图标。

### 3.2 移动与单击

- 按住并拖动黑洞只改变黑洞位置。
- 黑洞经过桌面文件、文件夹或其他窗口时，不读取、不选择、不导入任何内容。
- 黑洞跨越显示器边界后自动切换捕获源和坐标系统。
- 显示器断开时，黑洞移动到主显示器的安全可见区域。
- 短按且未发生拖动时视为单击：
  - 有待结算任务：打开最新待结算任务。
  - 没有待结算任务：打开主程序概览。

### 3.3 文件拖放

只有操作系统提供的外部文件拖放会触发导入：

1. Finder 或其他文件管理器开始文件拖放。
2. 支持的文件进入黑洞命中区域后，黑洞进入准备吞噬状态。
3. 文件离开命中区域时取消准备状态。
4. 用户在黑洞命中区域内松开鼠标后，才提交导入请求。
5. 一次拖放只处理第一个受支持文件。

首版允许：

- `.gcode.3mf`
- 包含切片 G-code 的 `.3mf`
- `.gcode` 保留现有安全限制，需要补充耗材配置后才能结算

未切片 3MF、损坏文件和不支持的扩展名不会创建任务，也不会修改耗材余额。

### 3.4 视觉状态

- 空闲：吸积盘缓慢旋转，黑洞后方画面产生真实折射。
- 移动：吸积盘轻微收紧，松手后做短促回弹。
- 文件靠近：黑洞扩大约 12%，外圈亮起，提示可放入。
- 文件吞噬：快速收缩、闪光，然后恢复设置尺寸。
- 等待结算：每个待处理任务对应一颗琥珀色轨道光点。
- 结算完成：绿色光环闪过一次，待处理光点减少。
- 导入失败：红色波纹向外扩散，任务不创建。
- 轻量黑洞：保留上述状态变化，但背景不折射。

黑洞本体不带固定矩形卡片。错误原因和权限说明显示在主程序或系统通知中。

## 4. 设置

主程序设置页增加“桌面黑洞”分组。

### 4.1 黑洞类型

- 真实黑洞
- 轻量黑洞

选择真实黑洞时检查屏幕录制权限。权限不可用时保持轻量黑洞运行，并在设置页显示处理方式。

### 4.2 尺寸

- 范围：120 至 360 px
- 快捷档位：小、中、大
- 滑杆支持精细调整
- 修改后桌面黑洞实时缩放并持久化

尺寸指黑洞宠物窗口的逻辑尺寸。Retina 显示器由原生渲染层按实际缩放因子分配纹理。

### 4.3 帧率

- 自动：空闲 30 FPS，移动、文件悬停和吞噬时 60 FPS，隐藏时暂停
- 30 FPS：固定省电模式
- 60 FPS：固定流畅模式

设置页说明高帧率会提高 GPU 与电量消耗。

### 4.4 显示与位置

- 显示黑洞
- 隐藏黑洞
- 重置到主显示器

位置是设备相关设置，不进入可迁移备份。

## 5. macOS 架构

### 5.1 组件边界

现有 Tauri 主程序保留 React 前端、Rust 任务服务和 SQLite 账本。新增原生 macOS 黑洞模块：

- `PetController`：Rust 状态协调器，管理可见性、模式、尺寸、帧率、位置和待结算数量。
- `PetPanel`：无边框透明 `NSPanel`，承载黑洞、鼠标拖动和原生文件拖放。
- `MacCaptureService`：使用 ScreenCaptureKit 捕获当前 `SCDisplay`。
- `MetalRenderer`：把捕获纹理、时间、尺寸、状态和动画进度送入 Metal Shader。
- `PetBridge`：通过稳定的 C ABI 在 Rust 与 Objective-C++ 原生模块之间传递命令和事件。

原生模块使用 Objective-C++，由 Cargo 构建脚本编译并链接以下系统框架：

- AppKit
- ScreenCaptureKit
- Metal
- MetalKit
- QuartzCore
- CoreMedia
- CoreVideo

这样可以避免把高频屏幕帧复制到 JavaScript，也不会依赖 WKWebView 的 `getDisplayMedia` 支持。

### 5.2 捕获策略

- 关闭音频、麦克风和鼠标光标捕获。
- 使用 `SCContentFilter` 捕获当前显示器并排除耗材管家自身进程。
- 捕获区域围绕黑洞窗口，并包含 Shader 需要的透镜边距。
- 黑洞移动时更新 ScreenCaptureKit 配置，不重建整个任务服务。
- 跨显示器时切换 `SCDisplay` 和内容过滤器。
- 捕获帧只存在于内存和 GPU 纹理，不写入磁盘。

### 5.3 真实扭曲

参考 Black Hole Timer 的 geodesic-tracing Shader，将 WebGL2 GLSL 逻辑移植到 Metal Shading Language。

渲染器接收黑洞后方同坐标区域的实时桌面纹理。Shader 对纹理采样坐标进行引力透镜变换，并叠加黑洞阴影、光子环和吸积盘。透明窗口只覆盖黑洞影响范围，因此黑洞区域以外仍由 macOS 正常响应和绘制。

### 5.4 轻量模式

轻量模式停用 ScreenCaptureKit。MetalRenderer 使用内部生成的透明或暗色纹理绘制黑洞和动画，不读取桌面像素。

如果 Metal 初始化失败，原生模块退化为低成本 Core Animation 黑洞，但文件拖放和任务功能保持可用。

## 6. 数据流

### 6.1 文件导入

1. `PetPanel` 的原生拖放目标收到文件 URL。
2. 原生层只做扩展名筛选，并将一个绝对路径交给 `PetController`。
3. `PetController` 调用现有 `PrintService::import_print_file`。
4. 解析成功后返回 `job_id`，黑洞播放吞噬动画并刷新待处理数量。
5. 解析失败时播放错误波纹，并通过本地通知或主程序显示稳定错误码。

### 6.2 任务结算

现有任务结算服务仍是唯一可以修改耗材余额的入口。黑洞导入不会扣除耗材。

打印结束后，用户在主程序选择成功、失败、取消或完成百分比。结算事务成功后，Rust 向 `PetController` 发布待处理数量变化，黑洞播放完成状态。

### 6.3 设置持久化

设备相关设置存入 `app_settings`：

- `pet_mode`
- `pet_size`
- `pet_fps`
- `pet_visible`
- `pet_x`
- `pet_y`
- `pet_display_id`

这些设置不进入业务备份，避免把另一台电脑的屏幕坐标和权限状态带入恢复。

## 7. 权限与隐私

- 首次启用真实黑洞时请求 macOS 屏幕录制权限。
- 如果系统要求重启应用，设置页显示明确提示。
- 拒绝权限后切换轻量黑洞，不循环弹窗。
- 用户可以随时在系统设置中撤销权限。
- 屏幕捕获不包含音频、麦克风或光标。
- 捕获帧不保存、不上传、不写日志。
- 应用日志不得包含桌面截图、完整打印文件路径或文件内容。

## 8. 性能与生命周期

- 自动模式按照交互状态在 30 和 60 FPS 之间切换。
- 黑洞隐藏时停止 ScreenCaptureKit 与 Metal 绘制。
- 系统休眠前暂停捕获，唤醒后重新枚举显示器和权限。
- 屏幕配置变化时重新校正位置、缩放因子和捕获区域。
- 渲染失败不会影响 SQLite、任务导入或耗材账本。
- 遵循 macOS“减少动态效果”设置，降低漂浮、回弹和闪光强度。

## 9. 单实例与旧版本处理

- 增加单实例保护。
- 第二次启动时不创建新托盘和新黑洞，只召回已有实例。
- 开发和打包脚本不得留下挂载中的临时 DMG 应用进程。
- 安装说明要求退出旧版本后再启动新版本。

### 11.1 自动测试

- 设置值验证与持久化。
- 120 至 360 px 尺寸边界。
- 自动、30 FPS、60 FPS 状态机。

- 鼠标移动黑洞不产生导入事件。
- 只有原生文件拖放完成才产生导入请求。

### 11.2 原生集成测试

- 使用合成纹理验证 Metal Shader 输出和透明边缘。

### 11.3 人工验收

- 在 Finder 图标上方移动黑洞，不选择、不读取、不导入文件。
- 从 Finder 把真实 `.gcode.3mf` 拖入黑洞并导入。
- 在两块显示器之间移动并持续正确折射。
- 权限授予、拒绝、撤销和重启。
- 30 FPS、60 FPS、自动模式和隐藏暂停。
- 睡眠唤醒、显示器热插拔和全屏应用。
- 主程序结算后黑洞状态同步。
- 长时间运行期间无第二个菜单栏图标、无捕获递归和无持续内存增长。

## 12. 完成标准

- 桌面只运行一个黑洞宠物和一个菜单栏图标。
- 真实模式能够折射黑洞后方的实时桌面画面。
- 黑洞可在所有显示器上拖动并正确恢复位置。
- 移动黑洞经过文件不会导入，只有文件拖入并松开才导入。
- 真实与轻量类型、120 至 360 px 尺寸、自动/30/60 FPS 均可在设置中调整。
- 文件导入、待处理提示和结算状态与现有业务逻辑一致。
- 屏幕画面与打印文件不离开本机。
- 全部自动测试、真实打印文件测试和 macOS 人工验收通过。
