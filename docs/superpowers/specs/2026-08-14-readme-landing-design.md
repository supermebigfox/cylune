# CYLUNE GitHub README 发布页设计

## 目标

把 GitHub 仓库首页改造成 CYLUNE 的正式产品入口。普通用户进入仓库后，应先看懂产品用途，并能直接下载 macOS 或 Windows 安装包；开发者仍可继续浏览源码。

## 页面结构

1. 顶部品牌区
   - 居中展示仓库内现有 CYLUNE Logo。
   - 使用 `CYLUNE` 作为主标题。
   - 一句话说明：面向 3D 打印工作流的本地耗材管理工具。
   - 不加入海报或新的二进制宣传素材。

2. 下载区
   - 放在产品介绍之前，减少用户寻找安装包的时间。
   - 分别提供 macOS 与 Windows 的 `v1.0` 直接下载链接。
   - 同时提供完整 Release 页面入口。
   - 明确 macOS 包仅支持 Apple Silicon。

3. 产品介绍
   - 说明 CYLUNE 连接耗材库存、切片数据与打印记录。
   - 说明同品牌、同材质、同颜色的不同料卷仍会独立记录余量。
   - 保持文字具体，不使用未经验证的性能、兼容性或自动化承诺。

4. 核心功能
   - 耗材库与拓竹原厂耗材目录。
   - `.3mf` 与 `.gcode.3mf` 的切片或数据读取。
   - 缩略图、打印盘、层数、时间和分色耗材克数记录。
   - 成功、失败与取消任务的耗材结算，以及重新打印流程。
   - 桌面黑洞拖入和打印历史。
   - 简体中文、繁体中文、英语及明暗主题。

5. 使用范围与安装提示
   - 当前版本以电脑端导入、切片和记录为主。
   - 不声称自动同步 Bambu Handy 或 MakerWorld 云打印任务。
   - 项目 3MF 切片依赖本机可用的 Bambu Studio 切片环境。
   - 提醒 macOS 尚未完成 Apple 公证，Windows 可能出现 SmartScreen 提示。

6. 项目信息
   - 链接到 GitHub Issues 与 Releases。
   - 最后一行显示 `Developer: Robin Lyu`。

## 验收标准

- 仓库根目录存在 `README.md`，GitHub 首页可以正常渲染。
- 页面顶部能看到 CYLUNE Logo、产品名和一句话定位。
- macOS 与 Windows 下载链接分别返回对应的 `v1.0` 安装包。
- 产品介绍覆盖耗材管理、切片数据、结算、黑洞导入和打印记录。
- README 明确当前工作流边界与安装提醒。
- 不提交本地海报、临时文件或其他未跟踪品牌资源。
