# CYLUNE 打印成功庆祝动效设计

日期：2026-07-31
状态：待书面规格复核

## 目标

当用户将打印任务结算为“打印成功”，并且本地结算与耗材扣减已经真正保存后，在 CYLUNE 当前应用窗口内播放一次具有明显仪式感的全量彩纸与烟花动画。

动效用于强化“打印完成且用量已记录”的正向反馈，但不能影响库存准确性、后续操作或系统其他窗口。

## 已确认的体验

- 采用视觉方案 3：全量彩纸与烟花庆典。
- 动效持续约 4 秒。
- 动效只覆盖 CYLUNE 的 WebView/应用窗口，绝不扩展到整个显示器，也不创建额外透明窗口。
- 动效层不接收鼠标或触控事件，播放过程中用户仍可继续操作 CYLUNE。
- 不播放声音。
- 亮色与暗色模式均保持可见，粒子颜色沿用 CYLUNE 的多巴胺色彩体系。

## 触发规则

庆祝动效必须由 `settleJob` 成功返回后触发，而不是由按钮点击触发。

以下条件全部满足时播放：

1. 用户本次提交的结算结果为 `success`。
2. 后端成功保存结算结果并完成耗材扣减。
3. 该次成功响应尚未在当前前端会话中触发过庆祝动效。

以下情况不得播放：

- 打印失败。
- 打印取消。
- 按打印进度估算。
- 结算 API 报错或被中断。
- 打开已经成功结算的历史记录。
- 撤销结算。
- 刷新项目或切换盘时重新读取到已有的成功结果。

## 组件边界

新增独立的 `SuccessCelebration` 展示组件，由应用根层渲染，以确保动画可以覆盖 CYLUNE 窗口内容，同时受 WebView 边界裁切。

`App` 负责维护一次性庆祝事件：

- `settleJob` 成功返回且 outcome 为 `success` 时生成一个新的庆祝事件标识。
- `SuccessCelebration` 收到新的事件标识后重新播放。
- 历史数据加载和普通状态刷新不得生成事件标识。

展示组件只接收播放事件，不读取或修改库存、任务、盘或切片数据，避免视觉功能与业务逻辑耦合。

## 动画设计

动画由两个同时进行的层次构成：

1. 多点烟花：从窗口左右及上半区分批爆发，火花向外扩散并受轻微重力影响。
2. 全量彩纸：从窗口上方与两侧喷入，旋转、飘落并逐渐淡出。

播放节奏：

- 0–0.4 秒：左右第一轮烟花快速爆发。
- 0.3–1.6 秒：彩纸密集进入，窗口上半区继续分批爆发烟花。
- 1.6–3.2 秒：彩纸自然飘落，零星火花补充。
- 3.2–4.0 秒：所有粒子逐渐淡出并自动卸载动画层。

实现优先使用 React、Canvas 2D 与现有 CSS，不引入大型第三方动画依赖。画布按设备像素比渲染，但限制最高倍率，避免 Retina 屏幕上产生不必要的 GPU 压力。

## 可访问性与性能

- 动画画布使用 `pointer-events: none`，不遮挡任何按钮。
- 画布尺寸只跟随 CYLUNE 窗口，不读取或捕捉桌面画面。
- 组件卸载、再次播放或窗口关闭时取消 `requestAnimationFrame` 和所有计时器。
- 系统启用 `prefers-reduced-motion: reduce` 时，不播放大范围移动粒子；改为约 700 毫秒的静态星光与柔和闪烁。
- 动画结束后移除画布，空闲时不保持渲染循环。
- 窗口尺寸变化时重建画布尺寸，粒子仍被窗口边界裁切。

## 测试标准

前端自动化测试至少覆盖：

1. 成功结算 API 返回后出现庆祝层。
2. API 尚未返回时不出现庆祝层。
3. API 失败时不出现庆祝层。
4. 失败、取消和估算结算均不出现庆祝层。
5. 打开已有成功历史记录不出现庆祝层。
6. 同一次成功事件只播放一次。
7. 新的成功结算可以再次播放。
8. 动画层不可接收指针事件，结束后自动移除。
9. `prefers-reduced-motion` 下使用降级效果。
