# CYLUNE 成功吸入双极射流设计

日期：2026-07-29  
状态：待用户复核书面规格

## 目标

当黑洞完整吸入受支持的打印文件后，播放一次短促的蓝白双极射流，明确表达“吸入成功”。动画必须与现有黑洞融为一体，不使用额外引导波纹，也不能改变黑洞的视觉直径或拖放范围。

受支持的文件包括：

- `.3mf`
- `.gcode.3mf`
- `.gcode`

其他普通文件仍执行“吸入后吐出”，不播放成功射流。

## 动画时序

1. 文件靠近命中范围：黑洞转速提高到常速的 2.4 倍，扭曲拉力提高到 1.7 倍，尺寸不变。
2. 用户松手：文件图标沿顺时针轨迹缩小并吸入中心，持续 0.74 秒。
3. 受支持文件完成吸入：从事件视界沿极轴同时喷出两束蓝白射流，持续约 0.5 秒。
4. 射流开始后执行已有导入回调；主程序继续解析文件并打开任务详情。
5. 不受支持文件：跳过射流，继续执行现有 0.62 秒吐出动画。
6. 文件离开命中范围或取消拖放：立即恢复正常转速与拉力，不播放射流。

这里的“成功吸入”指原生拖放层确认该文件是受支持的普通文件并完成吞噬动画。后续解析失败仍由现有导入错误流程处理。

## 视觉设计

- 无拖放、无射流时必须保持当前黑洞外观完全一致：颜色、轮廓、吸积盘、亮度、透明边界、视觉尺寸和运动基线均不得重调。
- 射流为上下对称的双极结构，方向垂直于吸积盘主轴。
- 核心为近白色，外缘为冷蓝和少量青色辉光，以便在浅色与深色背景上都可见。
- 射流从中心快速点亮，向两端延伸并收窄，随后由外向内衰减。
- 使用受时间驱动的细粒噪声制造高能粒子流动感，但不额外创建独立桌面粒子窗口。
- 射流只影响颜色、亮度和透明度；事件视界半径、吸积盘半径、拖放窗口和设置中的尺寸值均保持不变。
- 不使用环形冲击波、三条引导线或会被误认为拖放提示的波纹。
- `successJetProgress == 0` 时，Metal 输出必须与加入射流前的同一帧基础输出等价；射流只能作为短时附加层，不能改写基础黑洞参数。

## 实现边界

- 原生拖放状态机新增“成功射流”进度，范围为 `0...1`。
- Metal 参数新增成功射流进度，由现有全屏黑洞渲染层消费。
- 射流直接在 `BlackHole.metal` 中合成，继续使用当前实时桌面纹理和透明窗口。
- 成功射流与非打印文件吐出互斥，同一拖放代次只能进入其中一条分支。
- 现有源文件安全约束不变：不移动、不删除、不修改用户拖入的文件。

## 错误与中断

- 拖放取消、应用隐藏、休眠或退出时清零射流进度。
- 新一轮拖放开始时取消上一轮尚未完成的射流，避免叠加。
- Metal 不可用时跳过视觉射流，但文件导入流程继续运行。
- 射流播放不会阻塞解析线程或库存数据写入。

## 测试与验收

自动测试覆盖：

- 成功射流进度在吞噬结束前为零，在射流时段内从零推进到一。
- 受支持文件进入射流分支，其他文件只进入吐出分支。
- 靠近时转速与拉力增大，但黑洞视觉直径保持原值。
- 射流结束、拖放取消和失败分支均会清零进度。
- CPU 与 Metal 的参数布局保持一致，发布构建能编译着色器。

人工验收覆盖：

- `.gcode.3mf` 完整吸入后能看到清晰的蓝白双极射流。
- 普通图片或文本文件吸入后只吐出，不出现射流。
- 射流期间黑洞大小没有呼吸式放大或缩小。
- 浅色浏览器、深色窗口和桌面背景上均能看清射流。
- 连续拖入多个文件时不会遗留上一轮射流。
