# 拓竹 A1 + AMS Lite 耗材监控系统设计

## 目标

构建一个可在手机和电脑访问的耗材监控网站，并配套一个运行在用户电脑或低配单板机上的本地采集器。采集器自动监听拓竹 A1 的打印任务，识别 AMS Lite 槽位与颜色，在任务完成、失败或取消后按实际使用量更新库存。

第一版只支持一台 A1 和一套 AMS Lite，保留未来扩展多打印机的清晰接口，但不提前实现多设备管理。

## 系统结构

系统分为三个边界清晰的部分：

1. 在线网站负责库存展示、历史记录、低库存预警、换卷与人工校准。
2. 网站数据服务负责持久化耗材、打印任务、扣减明细和采集器状态。
3. 本地采集器通过局域网连接 A1，在设备开放对应能力时读取打印状态和打印文件，计算消耗后仅上传结构化结果。

打印机 IP、序列号和局域网访问码只保存在本地采集器的配置中，不上传到网站。网站不能向打印机发送控制命令。

## 支持的运行环境

同一套采集器核心逻辑支持：

- 当前 Mac 本机试运行；
- Raspberry Pi Zero 2 W；
- Raspberry Pi 3/4/5；
- Orange Pi Zero 3 等 ARM64 Debian/Ubuntu 设备。

Zero 2 W 只有 512MB 内存，因此采集器采用轻量常驻进程，不依赖 Docker。3MF 中的 G-code 解压和解析采用流式处理，内存占用有固定上限，不把完整打印文件加载到内存。

## A1 文件访问前提

精确的中途结算依赖两个彼此独立的能力：通过 MQTT 取得任务状态与停止位置，以及通过 FTP 取得打印机上的当前 3MF/G-code。A1 需要开启允许这些本地通道的开发者模式，并与采集器处于同一局域网。

拓竹公开说明开发者模式可以开放 A1 的 MQTT 和 FTP，但也明确说明其通信协议不属于官方支持接口。因此首次连接必须执行能力检测：验证状态订阅、当前文件定位、只读下载和样本解析。只有全部通过后，网站才显示“精确结算已启用”。

如果当前固件、打印来源或文件状态不允许读取打印文件，采集器改用本地切片文件捕获；两条路径都不可用时，只生成带“估算”标记的待确认记录，不声称得到精确克数。

## 网站界面

首页第一屏直接展示当前打印和四个 AMS Lite 槽位：

- 当前任务名称、状态、进度、当前层与预计剩余时间；
- 每槽颜色、材料、初始净重、剩余克数和剩余百分比；
- 低库存状态与采集器在线状态；
- 最近一次自动扣减的颜色和克数。

下方提供打印历史与耗材流水。每条打印记录展示成功、失败、取消或待确认状态，以及每种颜色的计划用量、实际扣减和计算依据。

用户可以执行换卷、校准剩余重量、修改低库存阈值、修正或撤销一次扣减。所有修正保留审计记录。

## 自动采集与结算

采集器订阅打印机的局域网状态，按打印任务建立唯一记录，并保存任务开始时的 AMS 槽位映射。

### 成功任务

任务成功完成后，解析打印文件中各工具的挤出量、材料直径与密度，结合 AMS 槽位映射换算为各颜色克数。换色冲刷和擦料塔等已包含在 G-code 挤出指令中的消耗一并计入。

### 失败或取消任务

采集器记录停止时的层数和进度，并只累计 G-code 中截至该位置的各工具挤出量。系统不会按整单扣减，也不会简单地用总耗材乘以进度百分比。

如果无法取得足够精确的停止位置，则采用进度比例生成估算结果，并将任务标记为“估算，待确认”。用户确认或修改后才形成最终流水。

### 断线与休眠

采集器断线或电脑休眠时不猜测库存变化。恢复连接后尝试使用打印机当前状态、最后任务信息和本地任务缓存进行补算。无法可靠恢复的任务进入待确认。

本机版本提供“运行时阻止主机休眠”选项，允许屏幕关闭但保持采集器联网。MacBook 合盖休眠不保证继续采集。

### 幂等性

每个打印任务使用稳定的任务标识结算。重复状态、断线重连和服务重启不会产生重复扣减。

## 数据模型

- `printers`：打印机显示名称及非敏感标识。
- `collector_status`：采集器版本、最后心跳、连接状态和运行平台。
- `spools`：颜色、材料、密度、初始重量、当前重量和预警阈值。
- `ams_slots`：四个槽位与当前耗材卷的映射。
- `print_jobs`：任务状态、开始/结束时间、层数、文件标识和结算置信度。
- `consumption_entries`：按任务、槽位和颜色记录的增减流水。
- `adjustments`：换卷、称重校准、人工修改和撤销记录。

库存余额由耗材卷初始值与不可变流水计算，同时保留缓存值用于快速展示。

## 配置与迁移

首次运行时，用户在本机设置页填写打印机局域网 IP、序列号和访问码，并执行 MQTT、FTP 与样本文件解析测试。敏感配置使用本机权限保护，不写入网站数据库或日志。

从电脑迁移到树莓派时：导出采集器配置、停止旧采集器、在新设备安装同版本、导入配置并测试连接。库存和历史保存在网站端，无需搬迁；本地仅迁移未完成任务缓存和设备凭据。

## 错误处理

- 打印机不可达：显示离线并重试，不修改库存。
- 文件缺失或损坏：任务进入待确认，不自动全额扣减。
- 固件关闭或改变本地文件访问：关闭“精确结算”状态，继续记录任务并要求确认估算结果。
- AMS 映射变化：使用任务开始时的映射；冲突时提示用户确认。
- 未知材料密度：使用材料默认密度并标记估算，允许用户校准。
- 上传失败：本地加密队列保留结果，网络恢复后重试。
- 重复事件：使用任务标识和结算版本去重。
- 低库存：在网站内提示；第一版不发送短信或邮件。

## 安全与隐私

- 网站永不保存打印机访问码。
- 本地采集器只读取状态和完成耗材计算所需的打印文件，不执行启动、暂停、停止等控制命令。
- 不上传完整 3MF、G-code、模型缩略图或模型几何数据。
- 上传内容限于任务名称、时间、状态、槽位映射、用量和诊断摘要。

## 验证方案

1. 使用录制的 A1 状态事件验证成功、失败、取消、断线和重复事件。
2. 使用单色、双色、多次换色和擦料塔样本验证分色 G-code 累计。
3. 在人为限制的 512MB 环境中解析大型 3MF，确认内存上限和可接受耗时。
4. 验证任务重放不会重复扣减。
5. 验证修改、撤销和换卷后的余额与流水一致。
6. 在本机完成模拟数据演示和连接配置流程；真实联调时由用户在本机输入访问码。

## 第一版交付范围

- 响应式在线耗材仪表盘；
- 四槽库存、当前打印、历史流水和低库存提醒；
- 本地采集器及 macOS 安装方式；
- Raspberry Pi Zero 2 W / ARM64 Linux 轻量安装方式；
- 模拟数据模式，用于没有打印机凭据时验证完整流程；
- 配置导出、导入与迁移说明。

不包含远程控制打印机、多用户权限、多打印机管理、短信/邮件提醒和耗材采购功能。
